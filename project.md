## 1. Executive Summary & Core Philosophy

**DAOvault AI** is an ultra-modern, decentralized Web3 affiliate and reward ecosystem built on the **BNB Smart Chain (BSC BEP-20)**. 

Inspired by the bleeding-edge visual presentation, 3D WebGL animations, and seamless one-click wallet onboarding of **TPR World (tprworld.org)**, DAOvault AI combines a **high-end futuristic luxury aesthetic** with a **mathematically closed, 100% sustainable marketing plan**:

1. **Zero Passive ROI (0%):** There are no daily returns, monthly percentages, or speculative staking schemes. Payouts occur strictly upon real network transactions.
2. **Instant Multi-Wallet Onboarding:** No email, password, or friction. One click on "Connect Wallet" immediately launches the native wallet dialog (MetaMask, Trust Wallet, SafePal, Binance Wallet, or WalletConnect).
3. **Lossless Referral Tracking:** The `?ref=CODE` query parameter is captured immediately in `<head>` before scripts execute, preventing referral loss during mobile wallet app switching.

5. **10× Sustainable Growth Cap:** Maximum cumulative earnings are capped at 10× package value ($3,000), guaranteeing long-term mathematical solvency.
6. **Transparent 5% Withdrawal Fee:** Automated 5% platform deduction on all earnings withdrawals to replenish community reward pools and liquidity.

### 3.3 Lossless Referral Routing (`?ref=CODE`)

To ensure no affiliate loses a downline attribution when links are shared on WhatsApp, Telegram, X, or YouTube:

```javascript
// Instant Pre-Execution Referral Capture (Runs at top of <head>)
(function () {
  try {
    const params = new URLSearchParams(window.location.search);
    const refCode = params.get("ref");
    if (refCode && refCode.trim() !== "") {
      localStorage.setItem("daovault_pending_ref", refCode.trim().toUpperCase());
    }
  } catch (e) {
    console.warn("Storage restricted", e);
  }
})();
```

- When the wallet connects, the backend reads `daovault_pending_ref` and permanently binds the sponsor relationship in the database/contract.

### 5.2 Database Schemas

#### 1. `users`
```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    wallet_address VARCHAR(42) UNIQUE NOT NULL,
    upline_id UUID REFERENCES users(id),
    referral_code VARCHAR(16) UNIQUE NOT NULL,
    active_directs_count INT DEFAULT 0,
    current_rank INT DEFAULT 0,
    total_packages_count INT DEFAULT 1,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
CREATE INDEX idx_users_wallet ON users(wallet_address);
CREATE INDEX idx_users_ref ON users(referral_code);
CREATE INDEX idx_users_upline ON users(upline_id);
```

#### 2. `packages`
```sql
CREATE TABLE packages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) NOT NULL,
    package_amount DECIMAL(18,2) DEFAULT 300.00,
    total_earned DECIMAL(18,2) DEFAULT 0.00,
    max_cap_limit DECIMAL(18,2) DEFAULT 3000.00,
    status VARCHAR(20) DEFAULT 'ACTIVE', -- ACTIVE, CAPPED, EXPIRED
    activation_tx_hash VARCHAR(66) UNIQUE NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

#### 3. `level_commissions`
```sql
CREATE TABLE level_commissions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    recipient_id UUID REFERENCES users(id) NOT NULL,
    source_id UUID REFERENCES users(id) NOT NULL,
    package_id UUID REFERENCES packages(id) NOT NULL,
    level INT NOT NULL, -- 1 to 20
    percentage DECIMAL(5,2) NOT NULL,
    amount_usd DECIMAL(18,2) NOT NULL,
    is_capped BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

#### 4. `rank_milestones`
```sql
CREATE TABLE rank_milestones (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) NOT NULL,
    rank_number INT NOT NULL, -- 1 to 11
    reward_amount DECIMAL(18,2) NOT NULL,
    power_leg_volume DECIMAL(18,2) NOT NULL,
    other_legs_volume DECIMAL(18,2) NOT NULL,
    status VARCHAR(20) DEFAULT 'QUALIFIED', -- QUALIFIED, PAID
    achieved_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

#### 5. `withdrawals`
```sql
CREATE TABLE withdrawals (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) NOT NULL,
    gross_amount DECIMAL(18,2) NOT NULL,
    fee_amount DECIMAL(18,2) NOT NULL, -- 5% flat fee
    net_amount DECIMAL(18,2) NOT NULL, -- 95% net transferred
    destination_wallet VARCHAR(42) NOT NULL,
    payout_tx_hash VARCHAR(66),
    status VARCHAR(20) DEFAULT 'PENDING', -- PENDING, PROCESSING, COMPLETED, REJECTED
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```
